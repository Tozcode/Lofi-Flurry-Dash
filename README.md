# Lofi-Flurry-Dash
Lofi Flurry Dash is a mobile-first mini-game for the CLAY Hackathon III. Drag Lofi the Yeti to catch flakes, gems and the rare Sui drop while dodging fire. Level up every 20 points to unlock new yeti outfits and ranks, from Snow Cub to Code Yeti. Includes power-ups, a leaderboard and sound. Plays instantly in any browser.
