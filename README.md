## About

Lofi the Yeti is stuck in the Flurry and you control his head: drag left and right to catch falling flakes and gems, dodge the fire, and grab the **Sui drop** that only shows up once you have survived for about a minute. Every 20 points Lofi levels up, switches outfit and earns a new rank, from **Snow Cub** all the way to **Code Yeti**.

It is built for the CLAY Hackathon III, the Lofi the Yeti community build competition on Sui Network.

## How to play

- **Drag** (touch or mouse) or use the **← →** keys to move Lofi.
- ❄️ Flake **+1** · 💎 Gem **+5** · 💧 Sui drop **+10** (appears after ~60 seconds)
- 🛡️ Shield blocks one hit · ⚡ Double points for 6 seconds
- 🔥 Fire costs a life. You have 3 lives.
- **Level up every 20 points.** Outfits: Snow → Violet → Jungle → Ash → Flame. Ranks: Snow Cub → Flurry Builder → Move Coder → Sui Maxi → Code Yeti.

## Features

- Mobile-first canvas game with touch, mouse and keyboard controls
- Level system with five yeti outfits, generated by tinting the Lofi head sprite at runtime
- Power-ups, particle effects, screen shake and synthesized sound effects (mutable)
- Menu, Leaderboard, Outfits, How to Play and CLAY Hackathon info screens
- Local leaderboard (top 10 scores on the player's device) and a share button
- Zero dependencies and no build step: the whole game is one `index.html`

## Run it

**Easiest:** open `index.html` in any modern browser.

**Local server (optional):**
```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, then **Save**.
4. After a minute your game is live at `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`.

## Tech

Plain HTML, CSS and JavaScript with the Canvas API and Web Audio. Images are embedded in `index.html` so the game works offline. The only external request is the optional Google Font (Lilita One), which falls back to a system font.

## Sui and on-chain status

This entry does not deploy a Move package, so there is no Package ID. Sui shows up as part of the game's theme: the Sui drop is the rarest, most valuable collectible. Wallet login and an on-chain leaderboard are planned next steps.
